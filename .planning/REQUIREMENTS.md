# Requirements: mp-card-creator

**Defined:** 2026-06-15
**Core Value:** Залил опросник + фото молда → получил готовый пакет для публикации на Ozon/WB.

## v1 Requirements

### Входные данные

- [x] **INP-01**: Пользователь загружает фото молда (≥1 фото) в форме опросника
- [x] **INP-02**: Пользователь указывает тип молда (лицо / руки / обувь / другое) в опроснике
- [x] **INP-03**: template.master.json содержит универсальные поля для любого типа молда (тип — параметр, не отдельный шаблон)

### Тексты

- [ ] **TXT-01**: Генерируются тексты для всех 5 размеров (XS–XL) на основе мастер-данных и типа молда
- [ ] **TXT-02**: Промпты учитывают тип молда из опросника — не упоминают «лицо» когда молд для рук
- [ ] **TXT-03**: Generator-critic цикл работает локально (retry идёт через прямой вызов хэндлера, без YMQ)

### Изображения

- [ ] **IMG-01**: Шаг 03-images запускается при нажатии кнопки в UI
- [ ] **IMG-02**: Генерируются инфографические слайды по зафиксированному шаблону (из примеров)
- [ ] **IMG-03**: Входное фото молда используется как reference при генерации слайдов
- [ ] **IMG-04**: Изображения сохраняются в output/ и доступны в UI

### Frontend

- [ ] **UI-01**: UI отображает реальные данные из API (хардкод LINES/TEXTS/IMAGES/VIDEO удалён)
- [ ] **UI-02**: Новая карточка, созданная через API, появляется в списке без перезагрузки страницы
- [ ] **UI-03**: UI показывает статус шага: «запущен» / «упал» / «готов» (через error-поле в манифесте)

### Надёжность

- [ ] **REL-01**: При падении шага в манифест записывается `{ error, failedAt }` — UI видит ошибку
- [ ] **REL-02**: E2E прогон: реальный опросник + фото проходит шаги 01–05 без ручного вмешательства

## v2 Requirements

### Видео

- **VID-01**: step-video / Kling.ai генерирует видео из изображений карточки
- **VID-02**: Polling Kling.ai работает локально без YMQ (прямой рекурсивный вызов)

### Масштабирование

- **SCL-01**: Атомарность манифеста под параллельными записями (optimistic locking или файл-локинг)
- **SCL-02**: Пагинация на GET /lines (limit/offset)
- **SCL-03**: GET /lines не делает DynamoDB Scan по всей таблице

### DevX

- **DEV-01**: Локальный YMQ-эмулятор для полноценного теста retry-цикла

## Out of Scope

| Feature | Reason |
|---------|--------|
| Отдельные шаблоны по типам молда (face.master.json, hands.master.json) | Один универсальный шаблон с полем moldType — проще поддерживать |
| OAuth / мультипользователи | Инструмент для одной команды, auth не нужен |
| Мобильная версия UI | Web-first |
| Публикация на маркетплейс через API | Только генерация файлов для ручной загрузки |
