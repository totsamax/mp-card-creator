| На панели шага 03-images | Кнопка «Изменить промпты» прямо над кнопкой «Генерировать» — контекстно там, где они нужны | ✓ |

## Хранение данных

| Option | Description | Selected |
|--------|-------------|----------|
| Перезапись prompts.images.json | Дешевле, наглядно, работает локально. Недостаток: при деплое в облако изменения теряются | |
| Оверрайд в манифесте артикула | Промпты хранятся в manifest.steps['03-images'].promptOverrides — работает в облаке, но привязан к конкретной линейке | |
| Отдельный prompts.images.user.json | Дополнительный файл поверх дефолтного — step-images читает его если есть, иначе фолбэк | |

**User's choice:** "Промт - часть линейки, все должно храниться в базе в YC"
**Notes:** Пользователь явно указал: промпт принадлежит линейке, хранить в YDB (Yandex Cloud). Не в локальном файле. Это означает per-article хранение в manifest/YDB документе.

## Содержание редактора

| Option | Description | Selected |
|--------|-------------|----------|
| 4 промпта (только) | main, infographic, scale, lifestyle — 4 текстовых поля. Без подсказок по токенам | |
| 4 промпта + подсказки по токенам | Рядом с полем — подсказка доступных {{moldName}}, {{color}}, {{topic}} и т.д. | |
| 4 промпта + feedbackSuffix + подсказки | Полный контроль над всем файлом — включая фразу повторной попытки критика | |

**User's choice:** "вариант 3 + нужна возможность делать более 4-х изображений. Промт тоже генерится в ИИ, соответственно надо чтобы по каждому изображению было описание от пользователя, сгенерированный по этому описанию промт и приложенные к этому запросу необходимые файлы от пользователя. У первых 4-х слайдов должны быть предзаполненные по-умолчанию описания, далее надо заполнять с нуля"
**Notes:** Это значительное расширение scope. Архитектура слайда: description (рус.) + generatedPrompt (AI из description, редактируемый) + files[]. Первые 4 — дефолты, дальше — произвольное количество с нуля.

## Цикл на слайд

| Option | Description | Selected |
|--------|-------------|----------|
| Описание → генерация всех сразу | Пользователь вводит описания для всех слайдов → нажимает «Генерировать» → AI генерирует промпты + изображения для всех в одном запуске | |
| Описание → промпт виден до генерации | Пользователь вводит описание → нажимает «Сгенерировать промпт» → AI даёт промпт → пользователь может поправить → затем «Генерировать изображение» | ✓ |
| Независимый цикл на каждый слайд | Каждый слайд можно генерировать отдельно: описание → промпт → изображение. Удобно для итераций | |

**User's choice:** "Описание → промпт виден до генерации"
**Notes:** Двухэтапный процесс per слайд: сначала генерируем технический промпт из описания, пользователь его видит и может отредактировать, затем запускает генерацию изображения.

## Прикрепляемые файлы

| Option | Description | Selected |
|--------|-------------|----------|
| Только референсные фото | Дополнительные фото молда/отливки — то же что и фото молда, но по позиции/ракурсу или для конкретного слайда | |
| Фото + шаблон фона | Дополнительные фото и изображение-шаблон для инфографики (текущий gpt-image-2 Edits API уже поддерживает background.png + фото молда) | |
| Любые файлы | Пользователь подбирает любые файлы на своё усмотрение — наибольшая гибкость, но сложнее в UI | ✓ |

**User's choice:** "Любые файлы"
**Notes:** Максимальная гибкость — пользователь сам решает что прикладывать. Файлы сохраняются в YDB/S3 под ключом article/03-images/slide-files/{slideId}/{filename}.

## Claude's Discretion

- Конкретный формат хранения slides в манифесте (manifest.slides vs manifest.steps['03-images'].slidesConfig)
- LLM-модель для "generate-prompt": gpt-4o-mini достаточно
- UX расположения кнопок на панели: "Добавить слайд" / порядок / drag-to-reorder
- Минимальная валидация: description непустое перед запросом промпта

## Deferred Ideas

- Drag-to-reorder слайдов — удобно, не блокирует MVP
- Preview сгенерированного изображения в самом редакторе (ImageView уже показывает)
- Версионирование конфигурации слайдов (history изменений)
- Глобальные шаблоны промптов (не per-article) — если понадобятся, отдельная фаза
