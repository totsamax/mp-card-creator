| T-999.1-08 | Tampering | slide id generated client-side | mitigate | Custom ids use `crypto.randomUUID()` prefixed `custom-`; server re-validates slideId against `/^[a-zA-Z0-9_-]{1,64}$/` (Plan 01) |
