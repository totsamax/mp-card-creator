### `functions/api/index.js` — new routes (route, request-response)

**Analog:** existing route matchers in `exports.handler` (l.116-156) + `handleRegenerate` (l.407) + `handleCreateLine` multipart path (l.241-273).

**Route-matcher pattern** — add after the article-extraction/validation block (l.119-123), alongside `/manifest` and `/steps/...` matchers. Copy the exact `rest.match(...)` + `decodeURIComponent` shape from l.133-153:
```javascript
// GET /lines/:id/slides  →  read slidesConfig | seed defaults
if (method === 'GET' && rest === '/slides') return await handleGetSlides(article);
// POST (NOT PUT — CORS, see Shared Patterns) /lines/:id/slides  →  save whole array
if (method === 'POST' && rest === '/slides') return await handleSaveSlides(article, event);
const genPromptM = rest.match(/^\/slides\/([^/]+)\/generate-prompt$/);
if (method === 'POST' && genPromptM) return await handleGeneratePrompt(article, decodeURIComponent(genPromptM[1]), event);
const slideRegenM = rest.match(/^\/slides\/([^/]+)\/regenerate$/);
if (method === 'POST' && slideRegenM) return await handleSlideRegenerate(article, decodeURIComponent(slideRegenM[1]), event);
```

**Article/id validation pattern** (copy from l.120): validate `slideId` the same way `article` is validated — `/^[a-zA-Z0-9_-]{1,64}$/` (matches `custom-<uuid>`). Return `respond(400, {error})` before any store call.

**Handler + respond pattern** — every handler is `async function handleX(article, ...)` returning `respond(status, body)` (l.489-495). Body-parse boilerplate to copy from `handleRegenerate` (l.408-417):
```javascript
let body = {};
if (event.body) {
  try {
    const raw = event.isBase64Encoded ? Buffer.from(event.body, 'base64').toString('utf8') : event.body;
    body = JSON.parse(raw);
  } catch { /* ignore */ }
}
```

**Multipart file-upload pattern** (for slide-file attach, D-09) — copy validation loop from `handleCreateLine` l.257-273 verbatim: non-image reject → `isImageBuffer` magic-byte gate (l.501) → `path.basename(...).replace(/[^a-zA-Z0-9._-]/g,'_')` filename sanitisation → `store.putArtifact`. Uses `event.files` (populated by local-server busboy) or `parseMultipartEvent(event)` fallback (l.199-226) for cloud:

```javascript
// ref: /lines/{article}/steps/slide-files/artifacts/{slideId}/{safeName}
```

**Analog:** `functions/step-texts/index.js` `generateTexts` (l.113-190) — the OpenAI fallback branch (l.172-189).

```javascript
const OPENAI_BASE  = (process.env.OPENAI_BASE_URL || 'https://api.openai.com/v1').replace(/\/$/, '');
const OPENAI_MODEL = process.env.OPENAI_MODEL || 'gpt-4o-mini';
// ...
const res = await fetch(`${OPENAI_BASE}/chat/completions`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${apiKey}` },

return data.choices[0].message.content.trim();
```

```javascript
if (!apiKey) return `${description} — mold ${sizeRecord?.moldName ?? ''}, ${sizeRecord?.color ?? ''}`;
```

### `functions/api/index.js` — `handleGetSlides` / `handleSaveSlides` / `patchSlide` (persistence)

**Analog:** `layers/shared/versionStore.js` `updateManifest` (l.31-57) + `deepMerge` (l.282-295); manifest-read pattern in `handleGetStep` (l.333-338).

**Defaults-seeding pattern** (D-03) — read manifest, fall back to a builder that reads `prompts.images.json`:
```javascript
async function handleGetSlides(article) {
  const manifest = await store.getManifest(article);
  const cfg = manifest?.steps?.['03-images']?.slidesConfig;
  return respond(200, cfg || buildDefaultSlides());
}
```
`buildDefaultSlides()` maps `promptsTmpl.imageTypes` → `{id, label, default:true, description: promptsTmpl.descriptions[id], generatedPrompt: promptsTmpl.prompts[id], files:[]}`. `feedbackSuffix` from `promptsTmpl.feedbackSuffix` (D-06).

**Whole-config save pattern** (POST /slides) — one `updateManifest` call, co-located under the consuming step (recommended `slidesConfig` shape, RESEARCH l.150-167):
```javascript
await store.updateManifest(article, '03-images', { slidesConfig: { feedbackSuffix, slides } });
```

**Single-slide read-modify-write** (avoids Pitfall 1 — `deepMerge` REPLACES arrays wholesale, versionStore l.286-287). For any per-slide field update, read the whole array, mutate by id, write the whole array back:
```javascript
async function patchSlide(article, slideId, patch) {
  const manifest = await store.getManifest(article);
  const cfg = manifest?.steps?.['03-images']?.slidesConfig || buildDefaultSlides();
  const slides = cfg.slides.map(s => s.id === slideId ? { ...s, ...patch } : s);
  await store.updateManifest(article, '03-images', { slidesConfig: { ...cfg, slides } });
  return slides.find(s => s.id === slideId);
}
```
> `updateManifest` is wrapped in `withManifestLock` per-article (versionStore l.271) — read-modify-write inside one handler is safe against parallel handlers.

**UUID for custom slides** (D-05) — `crypto.randomUUID()`; `crypto` already required at api l.3.


**Custom-slide handling** (Pitfall 5). `generateImageOpenAI` reads `SHARED/templates/{imageType}.png` (l.285) — custom slides have no template. **Cache-key fix** (Pitfall 6). `inputHash` currently hashes `{sizeRecord, imageType, promptsTmpl}` (l.46). Include the slide's `generatedPrompt` + file refs so an edited prompt invalidates cache; or rely on `force:true` from the UI (already sent, PipelineApp l.845).

## Shared Patterns

### Handler + respond envelope
**Source:** `functions/api/index.js:489-495`
**Apply to:** every new API handler
```javascript
function respond(statusCode, body) {
  return { statusCode, headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(body) };
}
```
Top-level try/catch already wraps `exports.handler` (l.157-160) → `respond(500,{error})`. Async step handlers additionally record `{error, failedAt}` to the manifest before returning 500 (step-images l.116-118).

### Input validation (V5 / ASVS)
**Source:** `functions/api/index.js:120` (id regex), `:267` (filename), `:501` (`isImageBuffer` magic bytes)
**Apply to:** all new routes with `article`/`slideId`/uploads
```javascript
if (!/^[a-zA-Z0-9_-]{1,64}$/.test(slideId)) return respond(400, { error: 'Invalid slideId' });
const safeName = path.basename(f.filename || '').replace(/[^a-zA-Z0-9._-]/g, '_');
if (!isImageBuffer(f.buffer)) return respond(400, { error: 'not a recognized image format' });
```

### CORS method constraint — POST not PUT
**Source:** `infra/local-server.js:167` → `'Access-Control-Allow-Methods': 'GET, POST, OPTIONS'`
**Apply to:** the save-slides route. D-10 literally says PUT, but PUT fails browser preflight. Use **POST /lines/:id/slides** (works in curl but breaks in the UI otherwise). Alternative: add PUT to `corsHeaders()` + router — larger change, not recommended.

### Persistence — updateManifest / deepMerge
**Source:** `layers/shared/versionStore.js:31-57`, `:271` (withManifestLock), `:282-295` (deepMerge)
**Apply to:** all slide persistence. Two rules: (1) `deepMerge` REPLACES arrays wholesale — single-slide edits must write the whole `slides` array back (read-modify-write); (2) `pushHistory` is the atomic append path — do not deep-merge into arrays.

### Artifact serving reuse
**Source:** `functions/api/index.js:356-405` (`handleGetArtifact`)
**Apply to:** slide-file retrieval — storing under pseudo-step `slide-files` v1 means `GET /lines/:id/steps/slide-files/artifacts/:name` works with zero new code (content-type detection + base64 already implemented).
