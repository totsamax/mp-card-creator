# mp-card-creator

Агентный пайплайн генерации карточек товаров (силиконовые молды) для
маркетплейсов Ozon и Wildberries.

- Архитектура, схема данных, версионирование, план развёртывания на
  Yandex Cloud — см. [`PROJECT_BRIEF.md`](./PROJECT_BRIEF.md)
- Прототип фронтенда (React) — [`frontend/PipelineApp.jsx`](./frontend/PipelineApp.jsx)
